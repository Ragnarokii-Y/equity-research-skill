# 公司深度研究：页面蓝图与视觉标准

本文件只保存通用、可复用的方法和实测版式参数，不包含保密样稿、样稿公司事实、原文、图片或品牌资产。正式制作时由使用者在当前任务提供本地样稿；仅在本地读取并应用，不把样稿或其提取素材加入 skill 发布包。

## 26 页标准角色

严格复刻任务保持 26 页和如下顺序；标题、产品分类、行业驱动和竞争对象根据目标公司重新研究。A/B/C 是三个分析方向，不代表任意公司必然有三项财务分部。

| 页 | 页面角色 | 正文论证及证据形式 |
|---|---|---|
| 1 | 封面 | 公司简称、研究日期，继承对应封面页型 |
| 2 | 研究结论 | 公司定位、财务表现、业务结构、业绩预测、风险；五项结论与后文一致 |
| 3 | 第一章过渡 | 公司介绍，章号及章节名 |
| 4 | 发展历程 | 时间阶段—战略重点—具体成果；上部正文，下部可编辑时间轴 |
| 5 | 股权结构 | 主要股东—控制关系—经营参与；统一截止日的可编辑股权图 |
| 6 | 规模与利润 | 营收/归母利润趋势—原因—经营含义；双图对照，金额柱+增速线 |
| 7 | 盈利与费用 | 毛利/净利率和四项费用率变化；双图及原因解释 |
| 8 | 分业务财务 | 收入构成、毛利贡献及驱动；两幅分部图，同一披露口径 |
| 9 | 业务架构 | 定位与能力—真实产品或业务—应用；收入结构变化和当期占比 |
| 10 | 业务方向 A | 定义及组成—公司具体壁垒—应用；产品/项目表与真实图片或自绘示意 |
| 11 | 业务方向 B | 同上；保留目标公司实际分类及阶段 |
| 12 | 业务方向 C / 新布局 | 同上或现有能力关系—研发产业化基础—应用及实际进展 |
| 13 | 第二章过渡 | 行业分析，章号及章节名 |
| 14 | 增量驱动一 | 驱动因素—需求变化—公司机会；匹配口径的市场/需求图 |
| 15 | 增量驱动二 | 技术或终端变化—产业传导—公司产品；图表或工艺示意 |
| 16 | 增量驱动三 | 新应用/需求—业务价值—公司进展；量化证据或工艺示意 |
| 17 | A 产业链 | 上游提供—中游完成—下游用途；三列链条图及公司位置 |
| 18 | A 竞争格局 | 竞争关键能力—主要企业—公司定位；可比维度竞争表 |
| 19 | B 产业链 | 同上，避免重复 A 方向内容 |
| 20 | B 竞争格局 | 同上，使用实际业务范围与参与者 |
| 21 | C 产业链 | 同上，区分参与产品与整个终端市场 |
| 22 | C 竞争格局 | 同上，对比真实能力、项目和客户应用 |
| 23 | 结构趋势与公司机会 | 产业变迁—公司积累—兑现路径；关键环节/公司布局表 |
| 24 | 第三章过渡 | 盈利预测与估值 |
| 25 | 盈利预测与估值 | 三年历史 A + 三年预测 E；收入、利润、增长、股本、EPS、ROE、ROA、PE、PEG；基准日行情 |
| 26 | 结束页 | 继承对应结束页型，仅使用任务授权的品牌资产 |

商品资源型公司的第 23 页可以讨论全球资源配置、产业链一体化或供需结构变化，不得强行套用设备国产替代叙事。若财务分部多于三个，应在第 8–9 页完整交代，再按实际价值链分组到第 10–12 页；避免将不同层级收入重复相加。

## 尺寸、版式与字形

- 宽 11,201,400 EMU，高 6,300,788 EMU；宽 882 pt，高约 496.125 pt，约 12.25 × 6.891 英寸，16:9。保留原生尺寸，不用近似宽屏值替代。
- 白底；顶部约 13 pt 高的横条、左上标识预留区、右上淡色装饰、正文标题左侧色块属于版式家具。保留几何位置；未明确授权沿用的机构标识、作者与机构口号须从母版、版式、正文、备注和文档属性移除。预留区可使用中性研究标识，不保留模板机构归属。不得把原素材嵌入 skill。
- 正文页标题左上约 `(25.2, 78.0)` pt，宽约 813–852 pt，高 39.7 pt。单行标题优先，概括本页主要内容/结论。
- 正文通常从 x≈25.2 pt、y≈120–128 pt 开始，宽约 812–835 pt，高约 105–143 pt。三段页面推荐框 `(25.2,124.6,824.4,134.9)` pt；页型原有范围优先。
- 图表/表格区域通常从 y≈278–305 pt 开始，到约 449–463 pt 结束。正文与图表之间留足间隔，不用图覆盖正文。
- 双图左侧 x≈34.6–45.5 pt、宽≈389 pt；右侧 x≈449–476 pt、宽≈396 pt。图标题跟随图左缘对齐。
- 产业链三列推荐左缘 44/313/583 pt，每列宽约 232.5 pt，列间使用方向箭头；红底白字的阶段表头、浅灰内容框。
- 竞争表推荐 x=34.6 pt，y=305 pt，总宽≈795.6 pt，4 列宽约 `140/275/200/180.6` pt；表头约 25 pt，内容行约 26 pt。列宽随实际内容合理调节，保持总体页型。
- 产品页可用左表右图：表格 x≈34.6 pt，宽≈439.2 pt（列宽约 `125/153/161.2`）；右侧图片两格 x≈494/685 pt，宽≈165 pt、高≈123 pt。图形等比缩放，不能裁掉产品关键部位。
- 盈利表推荐 x=34.6 pt、y=149 pt，总宽≈795.6 pt：指标列≈252 pt，六年列每列≈90.6 pt；约 11 行、每行 26.3 pt。补充行情信息另设简短注释，不塞入标题。
- 来源栏 y≈474.7 pt，左缘≈7.9 pt；页码位于右下角约 y=464–470 pt。
- 中文正文使用微软雅黑，拉丁字母保持同款匹配。已确认标准为：正文页标题 22.5 pt、正文 14 pt、表格及图表标题 12 pt、来源 8 pt。封面约 36 pt；过渡章节名约 28–36 pt、章号约 36–48 pt；结束页按相应页型。细小轴标签/脚注允许 8–10 pt，不能以缩小正文或表格解决空间不足。
- 正文左对齐，1.08 倍行距、段后约 4 pt；保持小箭头或同类项目符号。每段先有简短加粗结论，再跟普通字重的事实解释；禁止整段或连续数字全部加粗。
- 标题/品牌棕色以样稿主题有效色为准（已实测常见 `#984807`）；主要图表/表头红 `#C00000`，正文 `#000000`，图题灰 `#535353` 或 `#595959`，线/底 `#D9D9D9` 或 `#F2F2F2`，来源灰 `#808080`。图表系列优先红、浅灰、深灰，必要时辅色蓝 `#4F81BD`。主题继承颜色可能不同于 XML 直接颜色，需实际渲染确认。既有样稿的隐式标题字体可能继承旧字号；对确认标准显式设置 22.5 pt，同时保持原有定位、内边距、字重和中文/西文字体。

## 内容及取数的修正规则

1. 不从模板公司搬业务、客户、数据、技术或结论。产品分类、技术路线、下游应用、财务收入分类分开使用。
2. 每页题目—正文—图表共同证明同一个主题；三段业务正文顺序严格为产品是什么、目标公司的具体壁垒、应用及客户价值。
3. 不把行业高门槛当作公司的独有壁垒。壁垒须落在实际技术、资源禀赋、运营、研发、制造、客户验证、成本控制或项目经验。
4. 研发、样机、验证、验收、销售、批量销售分别核验；先进型号状态不得用整个产品系列状态替代。
5. 营业收入与主营业务收入、归母与扣非利润、直接持股与控制权、当年值与半年值均分清。半年和全年并列时明确期间，不从柱高计算同比。
6. 增速保留亏损/扭亏等真实经济含义；百分点与百分比分清；费用内已包含的股份支付不得重复扣减；产品毛利用收入减成本且与分部合计复核。
7. 一致预期保存原字段、公式、统计日、预测年度、单位、样本窗口和原值。平台字段为 0 不自动代表机构数为零；一个指标的样本数不能移用到另一指标。
8. 平台原值与自行计算指标区别记录。预测收入定义不清时核验厂商说明和返回结果；ROE、ROA、PE、PEG定义/单位不明时不补造数字。
9. 全部历史 PE 若用同一基准日市值除以往年利润，须在底稿标记，不能表示成历史交易 PE。E 股本若只是基准日股本，注明其性质，不假称未来股本预测。
10. 正式页内来源默认为“资料来源：公开资料、研究整理”；完整材料名称、原始文件名、原值和页码放独立底稿。正式页面不出现核验、调试、取数失败等工作话术。
11. 原生图表不保留依赖用户外部工作簿的链接。图表、股权、时间轴、财务表优先可编辑；真实图片只用于实物与示意，无生成模型补造数字、股权或项目关系。
12. 局部修订先记录授权范围。范围外页面 XML 与渲染像素应保持；发现范围外事实问题独立列示。完整制作则逐页扫描旧公司词、占位、错误标题和模板残留。

## 实施与验收

- 先用 `scripts/inspect_prototype.py` 读取当前任务的本地样稿；输出单独底稿到任务目录。默认不输出样稿原文，不复制图片；需要本地内容核对时显式添加 `--include-text`。
- 实测页型优先：保留尺寸、主题配色、页型家具几何和定位，替换目标公司的内容对象。清理未授权机构标识时还应删除对应且未共享的图片关系，避免被删图像以孤立媒体形式残留；重新打开文件确认完整。
- 用 `scripts/render_and_measure.ps1` 在本机 PowerPoint 中无窗口打开报告，导出逐页 PNG、PDF 和文本边界结果。它不会关闭用户已经打开的演示文稿，也不会退出用户的 PowerPoint。
- 边界测量是辅助证据；必须检查最终 26 张渲染图，核查长标题、表格、图注、坐标单位、负号、图例、图箭头、实物关键部位和页码。文字在画布内不代表没有重叠。
- 核验 PNG 数、PDF 页数和 PPTX 页数一致；每页证据能定位到独立来源清单；最终页面、备注、底稿与数值缓存一致。保持可编辑对象且数据计算可复现。


## 数值图形的尺度

金额、销量、需求等柱状图通常从0开始，避免截断柱高放大差异；比例堆叠图轴范围为0—100%。同比组合图金额与增速分别采用左右轴，保留负增长并明示单位。预测约数在标签或注释保留约数含义。核验显示轴、系列和原值，而不只检查数据缓存。

清理原作者与公司残留时还需检查PPTX的缩略图和元数据。修改OOXML保留原命名空间映射，特别是`xsi:type="dcterms:W3CDTF"`中的QName前缀；XML可解析不等于PowerPoint可打开。对文件进行实际打开和导出验证。

### 双轴与流程图易错点

- 双轴柱线图金额用左轴、同比用右轴。右侧位置通过与其对应的类别轴在最大类别处交叉实现；同时检查轴 ID/crossAx 成对一致。复制金额轴创建百分比轴时移除继承的非负最小值，确保负同比可见；比例/百分比格式与实际小数值一致。
- 箭头等单字对象也可能超过文字框，流程图优先使用原生连接符或箭头形状。

双轴交叉属性说明参考：[Microsoft Axis.Crosses](https://learn.microsoft.com/en-us/office/vba/api/excel.axis.crosses)。


如PowerPoint渲染仍把副轴同比标签放在左侧，可将副数值轴tickLblPos设为high（Excel枚举xlTickLabelPositionHigh），显式放在右侧；随后实际渲染验证，保留负同比与左右单位。
